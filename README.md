Mi principal experiencia práctica está en el desarrollo de aplicaciones móviles con Flutter y Dart, trabajando con BLoC, Cubit, Clean Architecture, Repository Pattern, Use Cases, APIs REST y persistencia local.

También he desarrollado proyectos Full-Stack y backend utilizando React, Vite, JavaScript, Python, Flask, C# y .NET, integrando APIs, bases de datos y diferentes mecanismos de persistencia.

Además, he explorado soluciones de inteligencia artificial aplicada mediante embeddings, Sentence Transformers, búsqueda semántica, similitud vectorial y pgvector.
